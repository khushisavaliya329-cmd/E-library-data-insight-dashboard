# E-Library Data Insight Dashboard

## Project Overview

The E-Library Data Insight Dashboard is a Python-based project developed to analyse library book borrowing records. It helps understand book popularity, user activity, borrowing duration and monthly borrowing trends.

## Objectives

- Analyse library transaction data.
- Find the most borrowed books.
- Calculate average borrowing duration.
- Identify the busiest day of the week.
- Understand borrowing patterns across different genres.
- Display results using graphs and charts.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Features

- CSV file loading and data validation.
- Removal of duplicate and missing records.
- Library statistics and calculations.
- Filtering transactions by genre, date and duration.
- Generation of a summary report.
- Four data visualisations.

## Visualisations

The project includes:

- Top 5 Most Borrowed Books (Bar Chart)
- Monthly Borrowing Trends (Line Graph)
- Borrowings by Genre (Pie Chart)
- Borrowing Activity by Day and Month (Heatmap)

## Project Files

- `elibrary-dashboard.py` – Main Python program.
- `library_transaction.csv` – Library transaction dataset.
- `library_summary_report.csv` – Generated summary report.
- `screenshots/` – Project output screenshots.

## How to Run

1. Install Python.
2. Install the required libraries:

   `pip install numpy pandas matplotlib seaborn`

3. Run the Python file:

   `py elibrary-dashboard.py`

4. Follow the menu displayed in the terminal.
